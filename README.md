
# Mittal Store – Online Grocery Website

## About the Project
Mittal Store is a responsive grocery shopping website built using HTML, CSS, and JavaScript. It allows users to explore grocery products through a simple and interactive interface.

## Features
- Responsive design for desktop, tablet, and mobile.
- Grocery product cards with prices.
- Product search functionality.
- Category filters for groceries.
- Shopping cart counter.
- Interactive banner slider.
- Product details popup modal.
- FAQ accordion.
- Smooth navigation between sections.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.

## Project Files
- `index.html` – Website structure.
- `style.css` – Styling and responsive layout.
- `script.js` – Interactive functionality.
- `README.md` – Project documentation.

## Note
This is a frontend demonstration project. It does not include real payments, user accounts, or backend order processing.
